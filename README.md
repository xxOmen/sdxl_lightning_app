
# 📝 **StyleMind AI – Outfit Prompt Generator** 👗

**Elevate your fashion game with your personal AI stylist.** This Streamlit app helps you create curated fashion prompts that bring your style vision to life. Whether you're designing moodboards, planning outfits for an event, or looking for styling inspiration, this tool provides tailored fashion prompts using an intuitive interface.

## 🚀 Features

- **Personalized Outfit Prompts**: 🎯 Select your occasion, season, style, and gender to generate a customized fashion concept.
- **Fashion Inspiration**: 💡 Choose from various fashion references (e.g., Euphoria characters, Instagram influencers).
- **Custom Notes**: ✍️ Add specific styling preferences to refine your outfit prompts.
- **Instant Results**: ⚡ Receive an AI-generated fashion prompt with just a click!

## 🛠️ Getting Started

Follow these simple steps to get started with the **StyleMind AI – Outfit Prompt Generator**.

### 1. Install Requirements

To run the app locally, first, clone the repository and install the necessary dependencies.

```bash
git clone https://github.com/yourusername/stylemind-app.git
cd stylemind-app
pip install -r requirements.txt
```

### 2. Run the App

Launch the app with the following command:

```bash
streamlit run stylemind_app.py
```

### 3. Use the App

Once the app is running, follow these steps to generate an outfit prompt:

1. **Select the Occasion**: 🎉 Choose the occasion for which you're designing the outfit (e.g., Date Night, Office Meeting, Travel).
2. **Choose the Gender**: 👨👩 Select Male, Female, or Unisex for the outfit style.
3. **Pick the Season**: 🌞❄️ Choose the appropriate season (e.g., Summer, Winter, etc.).
4. **Select a Style Type**: 👔👗 Choose from Casual, Formal, Streetwear, Business Casual, or other predefined options.
5. **Fashion Inspiration**: 💫 Optionally, select a fashion inspiration reference like Euphoria characters or Instagram influencers.
6. **Custom Notes**: ✨ Add any additional custom styling preferences to refine the outfit (e.g., "include an oversized blazer or earthy tones").
7. **Generate the Outfit Prompt**: 🔲 Click the **Generate Outfit Prompt** button to create your fashion concept.

### Example Output

Once you’ve selected your preferences, the app will generate a fashion prompt, such as:

```
A styled female outfit designed for a date night in the summer season. The fashion aesthetic is casual, aligned with seasonal trends and color harmony.

Scene 1: A Pinterest-style flat lay arranged on a soft beige background. Include topwear, bottomwear, footwear, and 2–3 accessories.
Scene 2: A mannequin fully dressed in the exact same outfit shown in Scene 1.
```

### Customizing the Experience

If you wish to customize the app further (e.g., adding new fashion references or styles), simply modify the input options in the app’s code.
